* Goal
Make safe cached diagnostics the primary troubleshooting entry point, keep sensitive raw evidence behind an explicit action, and ensure diagnostic actions target the inspected PiChat runtime.

* Scope
- Included: runtime-owned inspector views, safe snapshot UI, setup actions and probe wording, documentation, tests and compatibility.
- Excluded: automatic repair, raw export, consolidated diagnostic retention, comprehensive provider health checks and unrelated command removal.
- Imported design: [[file:legacy/pichat-diagnostics-improvement-plan.md][legacy proposal]] (original: .tmp/pichat-diagnostics-improvement-plan.md). It is preserved as historical design/context; tasks below are the authoritative work checklist.

* Acceptance criteria
- Reports for runtimes A and B coexist; actions from A's report never fall back to B, including after stop/forget.
- Safe refresh reads caches only, avoids RPC/process activity, and never includes raw transport data; raw inspection remains explicit and warned.
- Setup/probe actions use the viewed runtime and backend capabilities; setup process reuse requires matching target/context.
- Tests cover ownership, safety, stale-source behavior, nested view closure, bindings and compatibility. Run pichat/test/run-tests.sh; relevant RPC integration coverage uses --full per pichat/TESTING_GUIDELINES.md. Verify user bindings in a live Emacs session.

* Approach and decisions
- At import (before implementation), pichat/pichat-chat-diagnostics.el still uses shared *PiChat Diagnostics* and *PiChat Transport Diagnostics* buffers and has the old pichat-diagnostics-customize-transport command; no evidence of these proposed changes being implemented.
- Before implementation, read pichat/README.md, pichat/GLOSSARY.md and pichat/TESTING_GUIDELINES.md. Keep the glossary's runtime vs Pi session and Session History terminology.
- The legacy proposal holds the detailed behavior and design options; reconcile it against current code before promoting this plan to ready. Proposed keybindings are not final until conflicts are checked.
